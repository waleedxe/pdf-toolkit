# Privacy Policy

PDF Toolkit is designed to be private by default. This document explains, in plain terms,
what the application does and does not do with your data.

## Summary

**Your files are processed locally on your device. They are never uploaded.**

## What we collect

Nothing. PDF Toolkit has no accounts, no analytics, and no telemetry in the MVP.

## File processing

- All PDF and image operations (merge, split, extract, remove, rotate, reorder, conversion,
  watermarking, page numbering, protect, unlock) run **entirely on your device**.
- The application does **not** upload documents, and does **not** perform cloud conversion,
  remote OCR, or any hidden third-party processing.
- Temporary files created while processing live in an application-specific temporary
  directory on your device and are cleaned up after each job.

## Network

The MVP works fully offline and does not require an internet connection.

## Diagnostics

If crash or error reporting is added in the future, it will:

- redact file paths and file names where possible;
- never attach document contents;
- never include document text or images.

Such reporting will remain opt-in.

## Changes

This policy may be updated as the product evolves. Material changes will be documented in
the repository (for example, in `CHANGELOG.md`).
