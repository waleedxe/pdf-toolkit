PDF Toolkit

Fast, private PDF tools for Windows. Your files never leave your computer.

Download for Windows View source

Installer or portable .zip · the installer is unsigned, so SmartScreen warns on first run — choose More info → Run anyway.

Tools

  • Merge and split
  • Extract, remove and reorder pages
  • Rotate pages
  • Watermark (text and image)
  • Add page numbers
  • Protect with a password / unlock
  • PDF → images, images → PDF
  • Arabic text shaping and fonts

Private by design

Everything is processed on your device — no uploads, no cloud, no account, no telemetry. It works completely offline, and your original files are never overwritten.
